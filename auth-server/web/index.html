安装指南

2 步完成安装

  1. 第一步：安装 Windows 后台服务

    下载并运行 installer.exe，一键安装本地翻译引擎。安装后系统托盘中不会有图标，服务在后台静默运行。

    需要 Windows 10 或更高版本。首次运行可能弹出 SmartScreen 提示，点击"更多信息"→"仍要运行"即可。

  2. 第二步：加载浏览器扩展

    下载 extension.zip 并解压到一个文件夹。

    打开 Chrome 浏览器，在地址栏输入 chrome://extensions，打开右上角"开发者模式"开关，点击"加载已解压的扩展程序"，选择刚才解压的文件夹。
